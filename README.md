# Watchparty Finito

La liste des films et séries à regarder ensemble en watchparty : Films du Mois, DCU, The Batman, Marvel hors MCU (le chantier Doomsday) et Autre.

- `index.html` : la page (accueil, onglets, journal des visionnages).
- `data.json` : la liste elle-même. C'est ce fichier qu'on met à jour pour ajouter un titre, cocher un visionnage ou changer une date.

Sur GitHub Pages, la page est en lecture seule et affiche le contenu de `data.json`.
