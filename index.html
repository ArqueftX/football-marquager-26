Modifier la liste

Colle ton jeton GitHub pour cocher les visionnages, changer les dates et ajouter des titres. Il reste enregistré dans ce navigateur, nulle part ailleurs.

  1. Ouvre la page de création de jeton, connecté à ton compte GitHub. Le nom et la permission Contents sont déjà remplis.
  2. Choisis une date d'expiration.
  3. Repository access : « Only select repositories », puis football-marquager-26.
  4. Dans Permissions, vérifie que Contents apparaît avec « Read and write ». Sinon : Add permissions, tape « Contents », coche-le, puis choisis « Read and write » à côté.
  5. Clique sur Generate token, copie le jeton et colle-le ci-dessous.
